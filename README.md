# 📡 Communication Firewall Lab

> A humorous cybersecurity inspired investigation into message delivery, response latency and highly resilient communication barriers. 😂

---

## 🎯 Project Overview

This project presents a fictional cybersecurity inspired investigation into communication behaviour, message delivery, response latency and repeated follow-up attempts.

The investigation explores a familiar scenario:

> **The message was delivered. The message was sent. The response, however, appears to be behind a highly secure firewall.** 🛡️🤣

The project applies cybersecurity concepts such as monitoring, incident classification, threat assessment, resilience and defensive controls to an entirely harmless communication scenario.

---

## 🧪 Investigation Objectives

The objectives of this investigation are to:

- Monitor communication attempts
- Record message delivery status
- Analyse response latency
- Track follow-up attempts
- Assess communication resilience
- Classify the apparent communication barrier
- Document the investigation process

---

# 🧠 Lessons Learned

1. Not every communication channel provides an immediate response.
2. Message delivery does not guarantee a reply.
3. Persistence does not always defeat a firewall.
4. Documentation is important.
5. Professional communication should be maintained even when responses are delayed.
6. Sometimes the strongest security control is simply **not replying**. 😂
